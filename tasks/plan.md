# Robot 실행 계층과 Serial 이식 계획

사용자 범위: Robot 클라이언트·서버 및 제조사별 Profinet Serial 클라이언트까지 이식한다. 이미 이식한 순수 프로토콜을 재사용한다. 실물 장비 접근·커밋·푸시는 하지 않는다.

## 설계

- Robot은 `Robot/회사명/Clients`, `Robot/회사명/Servers`에 둔다. TCP·UDP는 기존 전송 계약을 주입한다. HTTP는 호출자가 소유한 HttpClient를 주입한다.
- 연결 세션과 초기화는 연결 세대에 종속시킨다. 미접속 요청 거부, 명시적 연결, 자동 재시도 금지 계약을 유지한다.
- Serial은 `Communication/ISerialClient`와 `Communication/Serial`에 포트 설정·전송·독점 교환을 둔다. 제조사 코드는 `Profinet/회사명/Clients`에서 순수 빌더·파서를 호출한다.
- System.IO.Ports는 netstandard2.0용 공식 패키지를 사용한다. 포트 어댑터를 주입하여 실물 COM 포트 없이 경계·시간 초과·재접속을 검증한다.
- CRC/LRC는 기존 공통 구현을 재사용한다. 지원 명령·오류·교환 순서를 참고 소스와 대조한다.
- 원본의 동작과 새 전송 수명주기 계약의 차이는 문서에 명시한다. 새 장치 기능이나 자동 재전송을 추측해서 추가하지 않는다.

## 검증

기준 상태: 앞선 프로토콜 이식 후 전체 291개 통과, 빌드 경고·오류 0개. 기존 미커밋 변경은 보존한다.

각 기능은 가상 포트 또는 루프백으로 패킷과 결과를 검증한다. 마지막에는 전체 콘솔 회귀와 Release 솔루션 빌드를 수행한다. 제조사별 이식 목록과 제외 근거, 참고 파일 SHA-256을 기록한다.
